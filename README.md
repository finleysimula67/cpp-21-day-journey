# C++ 21-Day Journey

A structured, hands-on study of modern C++ focused on language fundamentals, memory management, resource ownership, and software engineering practices.

## Overview

This repository documents practical exercises and experiments completed while studying C++. The focus is on understanding the language beyond syntax, particularly its compilation model, object lifetime, value semantics, and explicit resource management.

The goal is to build a reliable foundation for developing, debugging, and maintaining C++ applications.

## Topics

- Compilation, headers, and linking
- Pointers, references, and `const` correctness
- Classes, composition, and object lifetime
- Copy and move semantics
- RAII and resource management
- Smart pointers and ownership
- STL containers and basic exception handling
- Rule of Three and Rule of Five

## Repository Structure

- `days/` — Daily C++ exercises and implementations
- `notes/` — Technical notes and explanations
- `projects/` — Practical C++ projects
- `CORE-CPP-CONCEPTS.md` — Reference for core C++ concepts
- `README.md` — Project overview
- `LICENSE` — License information
- `.gitignore` — Files excluded from version control

## Objectives

- Develop a clear understanding of C++ memory and object lifetime.
- Practice resource ownership, copying, and moving.
- Apply concepts through small, testable programs.
- Build a foundation for larger C++ projects and further study.

## Approach

Concepts are explored through implementation, compilation, debugging, and review. The repository records practical learning and experimentation rather than claiming comprehensive mastery of the language.
