# C++ Learning Roadmap

## Purpose

This document tracks the progression of my C++ learning beyond the initial 21-day journey. It provides a reference for completed topics, areas requiring further practice, and concepts to explore next.

## Completed Foundations

- Compilation, preprocessing, and linking
- Headers, declarations, and definitions
- Pointers, references, and `const`
- Scope and object lifetime
- Classes and composition
- Copy construction and copy assignment
- Move construction and move assignment
- RAII and smart pointers
- Rule of Three and Rule of Five
- Basic STL containers, strings, loops, and exception handling

## Next Areas to Study

### 1. Modern C++ Fundamentals
- Rule of Zero
- `std::array`, `std::vector`, and `std::string`
- Iterators and standard algorithms
- `auto`, range-based loops, and structured bindings
- `enum class` and `constexpr`

### 2. Build and Development Tools
- CMake fundamentals
- Compiler warnings and debugging
- Unit testing
- Separating interfaces from implementations
- Organizing multi-file projects

### 3. Deeper Language Concepts
- Templates and generic programming
- References and value categories
- Lvalues, rvalues, and forwarding
- Standard library ownership types
- Undefined behavior and common memory errors

### 4. Practical Engineering
- File I/O
- Error handling and API design
- Data structures and algorithms
- Performance measurement and profiling
- Writing maintainable, testable code

## Practical Application

Apply these concepts through small projects before moving toward larger applications. Each project should reinforce specific language features and include clear build instructions.

## Learning Principles

- Understand the behavior before memorizing syntax.
- Prefer standard library abstractions over unnecessary manual resource management.
- Test assumptions with small, reproducible programs.
- Use compiler diagnostics and debugging tools to investigate problems.
- Revisit concepts through implementation rather than passive reading.

## Progress Tracking

Update this document as topics are studied and applied. Mark a topic complete only when it can be explained and used independently, not merely because an example compiled.

*This roadmap is a working document and may evolve as practical experience grows.*
